# 千葉ロッテマリーンズ ファンハブ Web App 2026

千葉ロッテマリーンズファンのための総合Webアプリケーション。  
**選手名鑑 / グラウンド型スタメン / 観戦記録＆勝率 / 現地フォトギャラリー** の全4機能を単一のHTMLファイル（`index.html`）で利用できます。

さらに、**Google Identity Services ログイン** および **Google Drive API (appDataFolder) クラウド同期** を標準搭載し、PCとスマホ間での完全データ共有に対応しています。

スマートフォン（iOS / Android）およびPCの双方に完全対応しています。

---

## 🌟 主な機能一覧

### 🔑 0. Google ログイン & Google Drive アプリ専用同期
- 画面上部に **「Googleでログイン」** ボタンを配置。
- Google Client ID（`735794584683-ga1e3p56fcnsej3jjaeme8ogo9vb2hc5.apps.googleusercontent.com`）がコード内に埋め込み済みのため、設定不要ですぐにログイン可能。
- ログイン後、ユーザーアバターと名前が表示され、**「☁️ Drive保存」「☁️ Drive復元」** ボタンで簡単同期。
- データはユーザー本人の Google Drive 内の保護領域（`appDataFolder`）に保存されるため、マイドライブを汚さず、安全かつ確実にスマホ・PC間でデータ同期が行えます。

### ⚾ タブ1：選手名鑑
- 全33選手をカードグリッド表示（背番号・名前・ポジション・マイコメント）
- 名前・ひらがな・背番号で**リアルタイム絞り込み検索**
- 投手 / 捕手 / 内野手 / 外野手の**ポジションフィルター**
- カードクリックで**モーダル**表示（球団公式URLリンク・YouTube応援歌検索・応援歌歌詞）
- 寺地 隆成 選手は「内野手」として登録済み。

### 📋 タブ2：ベストスタメン（グラウンド型UI）
- 実際の野球場をイメージしたグリーン基調の**グラウンドグラフィック**
- 外野（LF/CF/RF）・内野（3B/SS/2B/1B）・バッテリー（P/C）・指名打者（DH）の全10枠
- 打順設定（1〜9番 + ポジション + 選手）が**グラウンドにリアルタイム反映**
- 打順初期設定は全枠「LF（左翼手）」に統一
- **localStorage** に自動保存・復元・リセット可能

### 🎟️ タブ3：観戦記録＆勝率自動計算
- 観戦日 / 対戦相手（パ5＋セ6球団） / 開催球場（14球場） / 勝敗 / メモの入力フォーム
- 現地勝率を `.700` 形式で自動計算（`勝 ÷ (勝 + 敗)`）
- 参戦数・勝敗内訳・最多観戦球場を自動集計したダッシュボード
- ログ一覧（新しい順）・個別削除・全消去対応

### 📷 タブ4：現地観戦フォトギャラリー
- 観戦日 / 球場 / 対戦相手 / 写真ファイル（file input または D&D） / キャプションの投稿フォーム
- Instagram風 3列グリッド表示（スマホは2列）
- カードクリックで**ライトボックス**（拡大表示）
- 写真データは大容量対応のため **IndexedDB（localForage）** に保存

## 📲 データ保存＆同期方法

| 保存方法 | 説明 |
|----------|------|
| **☁️ Google Drive 同期 (推奨)** | ログイン後「☁️ Drive保存」「☁️ Drive復元」ボタンで、ユーザー自身の Google Drive (`appDataFolder`) と相互同期。スマホ↔PCで自動移行。 |
| **📥/📤 ローカルJSON** | ネット環境に依存せず、JSONファイルで保存・読み込み。 |
| **ブラウザ内自動保存** | スタメン/観戦記録は `localStorage`、写真は `IndexedDB` に保存。 |

## 🌐 スマホアプリ化 & GitHub Pages 公開手順

### 1. GitHub Pages でWeb上に公開（無料）
1. [GitHub](https://github.com/) で新規リポジトリ `marines-cheer-hub` を作成
2. `index.html` をアップロードして Commit
3. リポジトリの **Settings > Pages** で Branch を `main` に設定して Save
4. 発行されたURL（`https://<ユーザー名>.github.io/marines-cheer-hub/`）でどこからでもアクセス可能！

### 2. スマホの「ホーム画面に追加」してアプリ化
- **iPhone (Safari)**: 共有ボタンアイコン →「ホーム画面に追加」
- **Android (Chrome)**: メニュー (⋮) →「ホーム画面に追加」または「アプリをインストール」

## 📁 ファイル構成

```text
marines-cheer-hub/
├── index.html         # メインアプリ（HTML + CSS + JS 一体型・約98KB）
├── players.json       # 選手データ（33名）
├── README.md          # 本仕様書
├── assemble_v2.js     # index.html 再ビルド用スクリプト（parts/ を結合）
└── parts/
    ├── v2_css1.html   # CSS パート1（ベーススタイル・選手グリッド・Google UI）
    ├── v2_css2.html   # CSS パート2（グラウンド・観戦記録・ギャラリー・モーダル）
    ├── v2_body.html   # HTML ボディ（4タブ + モーダル + Google設定モーダル）
    ├── v2_js1.js      # JavaScript パート1（タブ・選手・モーダル・グラウンドUI）
    └── v2_js2.js      # JavaScript パート2（観戦記録・ギャラリー・Google Auth/Drive Sync）
```

## 🔄 選手データ更新 / 再ビルド方法

`players.json` または `parts/` 内のファイルを編集した後、ターミナルで以下を実行：

```bash
node assemble_v2.js
```

`index.html` が自動的に再生成されます。
