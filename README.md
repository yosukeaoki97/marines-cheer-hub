# 千葉ロッテマリーンズ ファンハブ Web App 2026

千葉ロッテマリーンズファンのための総合Webアプリケーション。  
**選手名鑑 / 厳格な幾何学グラウンド型スタメン / 観戦記録＆勝率 / 現地フォトギャラリー / 成績・日程クイックリンク / マリーンズAIチャット** の全機能を単一のHTMLファイル（`index.html`）で利用できます。

さらに、**Google Identity Services ログイン** および **Google Drive API (appDataFolder) クラウド同期** を標準搭載し、PCとスマホ間での完全データ共有に対応しています。

スマートフォン（iOS / Android）およびPCの双方に完全対応しています。

## 🌟 主な機能一覧

### 📋 1. ベストスタメン（美しいダイヤモンド白線＆C・DH絶対座標配置グラウンドUI）

#### 幾何学守備配置（DH完全CSSリセット＆右側ファウルゾーン配置）
DH（指名打者）の余計なCSS計算（`left` や `transform`）を完全リセットし、`left: auto !important; right: 8% !important; transform: none !important;` により右側ファウルゾーンへ確実に絶対配置しました：

```text
┌─────────────────────────────────────────────────────────┐
│       CHIBA LOTTE MARINES ─ STARTING LINEUP             │
│                                                         │
│                     【CF 中堅手】                        │  ← 中央縦軸 (50%) 最奥
│                                                         │
│     【LF 左翼手】                     【RF 右翼手】       │  ← 左右対称・扇形
│                                                         │
│            【SS 遊撃手】   ⬡(2塁)  【2B 二塁手】          │  ← 2塁ベース周辺
│                                                         │
│                      【P 先発投手】                      │  ← 中央縦軸 (50%) マウンド
│                                                         │
│ ⬡(3塁)                                       ⬡(1塁)    │  ← ダイヤモンド角・塁上
│     【3B 三塁手】                     【1B 一塁手】       │
│                                                         │
│ ─────────────────────────────────────────────────────── │
│                      ⬡ (本塁ベース)                      │  ← 完全に露出・視認できる五角形
│                                                         │
│                      【C 捕手】            ┆DH 指名打者┆ │  ← 50%軸直下にC ＆ 【右端8%に完全リセット配置DH】
└─────────────────────────────────────────────────────────┘
```

- **DH（指名打者）の完全リセット絶対配置**: `position: absolute !important; left: auto !important; right: 8% !important; transform: none !important;` により、グラウンド右側ファウルゾーンへ確実に配置。
- **C（捕手）の絶対配置**: `position: absolute; left: 50%; transform: translateX(-50%);` でホームベースの真下に重ならずに配置。マウンド上の投手と直線上で完全に正対。
- **中央縦軸（50%ライン）の完全整列**: **CF ➔ 2B ➔ P（マウンド） ➔ ホームベース ➔ C（捕手）** が一直線上に完全整列。
- **ダイヤモンド白線**: ホーム ➔ 1塁 ➔ 2塁 ➔ 3塁 ➔ ホームを結ぶ正方形ダイヤモンドの綺麗な白線のみを描画。

#### 連動・操作機能
- **選手名鑑モーダル連動**: グラウンド上の各ポジションカードをタップすると `players.json` から該当選手の詳細モーダル（公式リンク・応援歌歌詞・YouTube等）をダイレクト表示
- **ガラスモーフィズムカード**: 透過ガラス質感（`backdrop-filter: blur(14px)`）＋ホバー時ネオンブルー発光
- **オーダーロジック完全保持**: 1〜9番 + 先発投手 (SP)、Google Drive & `localStorage` 保存・復元・リセット

## 📲 データ保存＆同期方法

| 保存方法 | 説明 |
|----------|------|
| **☁️ Google Drive 同期 (推奨)** | ログイン後「☁️ Drive保存」「☁️ Drive復元」ボタンで、ユーザー自身の Google Drive (`appDataFolder`) と相互同期。スマホ↔PCで自動移行。 |
| **📥/📤 ローカルJSON** | ネット環境に依存せず、JSONファイルで保存・読み込み。 |
| **ブラウザ内自動保存** | スタメン/観戦記録は `localStorage`、写真は `IndexedDB` に保存。 |

## 🌐 スマホアプリ化 & GitHub Pages 公開手順

1. **GitHub Pages でWeb上に公開（無料）**
   - リポジトリ `marines-cheer-hub` に `index.html` をアップロードして `Settings > Pages` から公開。
2. **スマホの「ホーム画面に追加」してアプリ化**
   - iPhone (Safari): 共有アイコン →「ホーム画面に追加」
   - Android (Chrome): メニュー (⋮) →「ホーム画面に追加」

## 📁 ファイル構成

```text
marines-cheer-hub/
├── index.html         # メインアプリ（HTML + CSS + JS 一体型・約119KB）
├── players.json       # 選手データ（33名）
├── README.md          # 本仕様書
├── assemble_v2.js     # index.html 再ビルド用スクリプト（parts/ を結合）
└── parts/
    ├── v2_css1.html   # CSS パート1（ベース・選手グリッド・Google UI・AIチャット）
    ├── v2_css2.html   # CSS パート2（幾何学SVGグラウンド・C/DH絶対配置）
    ├── v2_body.html   # HTML ボディ（4タブ + モーダル + 独立C/DH構造）
    ├── v2_js1.js      # JavaScript パート1（グラウンドカード名鑑タップモーダル連動）
    └── v2_js2.js      # JavaScript パート2（観戦記録・ギャラリー・Google Sync・AI Chat）
```

## 🔄 再ビルド方法

`players.json` または `parts/` 内のファイルを編集した後、以下を実行：

```bash
node assemble_v2.js
```

`index.html` が自動的に再生成されます。
