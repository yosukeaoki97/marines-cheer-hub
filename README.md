# 千葉ロッテマリーンズ ファンハブ Web App 2026

千葉ロッテマリーンズファンのための総合Webアプリケーション。  
**選手名鑑 / グラウンド型スタメン / 観戦記録＆勝率 / 現地フォトギャラリー / 成績・日程クイックリンク / マリーンズAIチャット** の全機能を単一のHTMLファイル（`index.html`）で利用できます。

さらに、**Google Identity Services ログイン** および **Google Drive API (appDataFolder) クラウド同期** を標準搭載し、PCとスマホ間での完全データ共有に対応しています。

スマートフォン（iOS / Android）およびPCの双方に完全対応しています。

---

## 🌟 主な機能一覧

### 📊 1. 成績・日程クイックモーダル (新機能)
- ヘッダー右側の **「📊 成績・日程」** ボタンをタップするとスポナビの主要ページへのカード型リンク集が開きます。
  - 🗓️ ロッテ1軍 試合日程・一球速報 (スポナビ)
  - 📊 ロッテ チーム・個人成績 (スポナビ)
  - 🏆 プロ野球 順位表 (スポナビ)
- すべて別タブ（`target="_blank"`）で開く安全設計。

### 💬 2. マリーンズAIチャット (新機能)
- 画面右下のフローティングボタン **「💬」** をタップすると、チャットウィジェットがポップアップ開閉。
- マリーンズに特化したAIアシスタント「マリーンズAI」と会話が楽しめます。
- 「日程」「成績」「スタメン」「観戦」「ZOZOマリン」「荻野」「藤原」「小島」などのキーワードに即座に応答。

### 🔑 3. Google ログイン & Google Drive アプリ専用同期
- 画面上部に **「Googleでログイン」** ボタンを配置。
- Google Client ID（`735794584683-ga1e3p56fcnsej3jjaeme8ogo9vb2hc5.apps.googleusercontent.com`）がコード内に埋め込み済み。
- ログイン後、**「☁️ Drive保存」「☁️ Drive復元」** ボタンで、ユーザー本人の Google Drive (`appDataFolder`) と安全に同期できます。

### ⚾ 4. タブ1：選手名鑑
- 全33選手をカードグリッド表示（背番号・名前・ポジション・マイコメント）
- カード内に **「📊 スポナビ成績」** ボタンを配置。タップで個人の最新成績ページへ直接移動可能。
- リアルタイム絞り込み検索・ポジションフィルター
- カードクリックで**詳細モーダル**表示（球団公式URLリンク・スポナビ個人成績・YouTube応援歌検索・応援歌歌詞）
- 寺地 隆成 選手は「内野手」として登録済み。

### 📋 5. タブ2：ベストスタメン（グラウンド型UI）
- グリーン基調の**グラウンド型フォーメーションUI** (10枠)
- 打順設定（1〜9番 + ポジション + 選手）が**グラウンドにリアルタイム反映**
- 打順初期設定は全枠「LF（左翼手）」に統一
- **localStorage** に自動保存・復元・リセット可能

### 🎟️ 6. タブ3：観戦記録＆勝率自動計算
- 観戦日 / 対戦相手 / 開催球場 / 勝敗 / メモの入力フォーム
- 現地勝率を `.700` 形式で自動計算（`勝 ÷ (勝 + 敗)`）
- 参戦数・勝敗内訳・最多観戦球場を自動集計したダッシュボード

### 📷 7. タブ4：現地観戦フォトギャラリー
- 観戦日 / 球場 / 対戦相手 / 写真ファイル / キャプションの投稿フォーム
- Instagram風 3列グリッド表示（スマホは2列）、拡大ライトボックス表示
- 大容量対応のため **IndexedDB（localForage）** に保存

## 📲 データ保存＆同期方法

| 保存方法 | 説明 |
|----------|------|
| **☁️ Google Drive 同期 (推奨)** | ログイン後「☁️ Drive保存」「☁️ Drive復元」ボタンで、ユーザー自身の Google Drive (`appDataFolder`) と相互同期。スマホ↔PCで自動移行。 |
| **📥/📤 ローカルJSON** | ネット環境に依存せず、JSONファイルで保存・読み込み。 |
| **ブラウザ内自動保存** | スタメン/観戦記録は `localStorage`、写真は `IndexedDB` に保存。 |

## 🌐 スマホアプリ化 & GitHub Pages 公開手順

1. **GitHub Pages でWeb上に公開（無料）**
   - リポジトリ `marines-cheer-hub` に `index.html` をアップロードして `Settings > Pages` から公開。
2. **スマホの「ホーム画面に追加」してアプリ化**
   - iPhone (Safari): 共有アイコン →「ホーム画面に追加」
   - Android (Chrome): メニュー (⋮) →「ホーム画面に追加」

## 📁 ファイル構成

```text
marines-cheer-hub/
├── index.html         # メインアプリ（HTML + CSS + JS 一体型・約112KB）
├── players.json       # 選手データ（33名）
├── README.md          # 本仕様書
├── assemble_v2.js     # index.html 再ビルド用スクリプト（parts/ を結合）
└── parts/
    ├── v2_css1.html   # CSS パート1（ベース・選手グリッド・Google UI・AIチャット）
    ├── v2_css2.html   # CSS パート2（グラウンド・観戦記録・ギャラリー・モーダル）
    ├── v2_body.html   # HTML ボディ（4タブ + モーダル + AIチャットUI）
    ├── v2_js1.js      # JavaScript パート1（タブ・選手・モーダル・グラウンドUI）
    └── v2_js2.js      # JavaScript パート2（観戦記録・ギャラリー・Google Sync・AI Chat）
```

---

## 🔄 再ビルド方法

`players.json` または `parts/` 内のファイルを編集した後、以下を実行：

```bash
node assemble_v2.js
```

`index.html` が自動的に再生成されます。
