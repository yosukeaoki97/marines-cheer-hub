# 千葉ロッテマリーンズ ファンハブ Web App 2026

千葉ロッテマリーンズファンのための総合Webアプリケーション。  
**選手名鑑 / リアル奥行きダイヤモンド・グラウンド型スタメン / 観戦記録＆勝率 / 現地フォトギャラリー / 成績・日程クイックリンク / マリーンズAIチャット** の全機能を単一のHTMLファイル（`index.html`）で利用できます。

さらに、**Google Identity Services ログイン** および **Google Drive API (appDataFolder) クラウド同期** を標準搭載し、PCとスマホ間での完全データ共有に対応しています。

スマートフォン（iOS / Android）およびPCの双方に完全対応しています。

---

## 🌟 主な機能一覧

### 📋 1. ベストスタメン（リアル奥行きダイヤモンド配置 ＆ 選手タップ名鑑連動）

#### 守備配置レイアウト（2段階奥行き式）
内野手の配置を実際の野球のダイヤモンドに合わせたリアルな2段階奥行きレイアウトに刷新しました：

```
【外野】  LF  ───────  CF  ───────  RF

【内野奥】    SS  ─────────────  2B
                  （二塁ベース周辺・外野寄り）

【内野前】  3B  ─────────────────  1B
            （三塁ベース寄り・前目）  （一塁ベース寄り・前目）

【投手】        P  ─────  C
```

- **SS（遊撃手）& 2B（二塁手）**: 二塁ベース寄り・外野側（奥側）に配置
- **3B（三塁手）& 1B（一塁手）**: 一・三塁ベース寄り・前目に配置
- 白線ダイヤモンド・アンツーカー土・ベースマーカーとのビジュアル整合性を確保

#### その他グラウンドUI機能
- **選手名鑑モーダル連動**: グラウンドの各ポジションカードをタップすると `players.json` から該当選手の詳細モーダルを表示
- **ガラスモーフィズムカード**: 透過ガラス質感（`backdrop-filter: blur(14px)`）＋ホバー時ネオンブルー発光
- **立体ベース・マウンドビジュアル**: 本塁（五角形）・1B/2B/3B（正方形ダイヤ型）・ピッチャーマウンド（アンツーカーサークル）
- **オーダーロジック完全保持**: 1〜9番 + 先発投手 (SP)、Google Drive & `localStorage` 保存・復元・リセット

### 📊 2. 成績・日程クイックモーダル
- ヘッダー右側の **「📊 成績・日程」** ボタンからスポナビ主要ページへ直接移動：
  - 🗓️ ロッテ1軍 試合日程・一球速報 (スポナビ)
  - 📊 ロッテ チーム・個人成績 (スポナビ)
  - 🏆 プロ野球 順位表 (スポナビ)

### 💬 3. マリーンズAIチャット
- 画面右下のフローティングボタン **「💬」** でチャットウィジェットが開閉。
- 「日程」「成績」「スタメン」「観戦」「ZOZOマリン」「荻野」「藤原」「小島」などのキーワードにフレンドリーに応答。

### 🔑 4. Google ログイン & Google Drive アプリ専用同期
- 画面上部に **「Googleでログイン」** ボタンを配置。
- Google Client ID（`735794584683-ga1e3p56fcnsej3jjaeme8ogo9vb2hc5.apps.googleusercontent.com`）が埋め込み済み。
- **「☁️ Drive保存」「☁️ Drive復元」** ボタンで、ユーザー本人の Google Drive (`appDataFolder`) と安全に同期。

### ⚾ 5. タブ1：選手名鑑
- 全33選手をカードグリッド表示（背番号・名前・ポジション・マイコメント）
- 各カード内に **「📊 スポナビ成績」** ボタンを配置
- リアルタイム検索・ポジションフィルター・詳細モーダル（公式URL・YouTube応援歌検索・歌詞）
- 寺地 隆成 選手は「内野手」として登録済み。

### 🎟️ 6. タブ3：観戦記録＆勝率自動計算
- 観戦日 / 対戦相手 / 開催球場 / 勝敗 / メモの入力フォーム
- 現地勝率を `.700` 形式で自動計算（`勝 ÷ (勝 + 敗)`）
- 参戦数・勝敗内訳・最多観戦球場を自動集計したダッシュボード

### 📷 7. タブ4：現地観戦フォトギャラリー
- 観戦日 / 球場 / 対戦相手 / 写真ファイル / キャプションの投稿フォーム
- Instagram風 3列グリッド表示（スマホは2列）、拡大ライトボックス表示
- 大容量対応のため **IndexedDB（localForage）** に保存

## 📲 データ保存＆同期方法

| 保存方法 | 説明 |
|----------|------|
| **☁️ Google Drive 同期 (推奨)** | ログイン後「☁️ Drive保存」「☁️ Drive復元」ボタンで、ユーザー自身の Google Drive (`appDataFolder`) と相互同期。スマホ↔PCで自動移行。 |
| **📥/📤 ローカルJSON** | ネット環境に依存せず、JSONファイルで保存・読み込み。 |
| **ブラウザ内自動保存** | スタメン/観戦記録は `localStorage`、写真は `IndexedDB` に保存。 |

## 🌐 スマホアプリ化 & GitHub Pages 公開手順

1. **GitHub Pages でWeb上に公開（無料）**
   - リポジトリ `marines-cheer-hub` に `index.html` をアップロードして `Settings > Pages` から公開。
2. **スマホの「ホーム画面に追加」してアプリ化**
   - iPhone (Safari): 共有アイコン →「ホーム画面に追加」
   - Android (Chrome): メニュー (⋮) →「ホーム画面に追加」

## 📁 ファイル構成

```text
marines-cheer-hub/
├── index.html         # メインアプリ（HTML + CSS + JS 一体型・約118KB）
├── players.json       # 選手データ（33名）
├── README.md          # 本仕様書
├── assemble_v2.js     # index.html 再ビルド用スクリプト（parts/ を結合）
└── parts/
    ├── v2_css1.html   # CSS パート1（ベース・選手グリッド・Google UI・AIチャット）
    ├── v2_css2.html   # CSS パート2（リアル奥行き内野・2段階配置・ガラスモーフィズムグラウンド）
    ├── v2_body.html   # HTML ボディ（4タブ + モーダル + 2段階内野行レイアウト）
    ├── v2_js1.js      # JavaScript パート1（グラウンドカード名鑑タップモーダル連動）
    └── v2_js2.js      # JavaScript パート2（観戦記録・ギャラリー・Google Sync・AI Chat）
```

## 🔄 再ビルド方法

`players.json` または `parts/` 内のファイルを編集した後、以下を実行：

```bash
node assemble_v2.js
```

`index.html` が自動的に再生成されます。
